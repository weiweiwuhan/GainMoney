# GainMoney 本地看盘

需要 Python 3.10 或更高版本，无需安装第三方依赖。

```bash
python3 server.py
```

在运行服务的机器上打开 http://127.0.0.1:8000。云环境预览可用 `python3 server.py --host 0.0.0.0 --port 8000` 启动，具体入口由云环境的端口映射决定。

## 行情和自选

默认跟踪上证指数（SH000001）、创业板指数（SZ399006）、科创50（SH000688）和科创100（SH000698）。页面按约 10 秒的间隔查询新浪财经的免费公开报价，缺失时补查东方财富。行情时间由数据源提供，休市、上游延迟或请求超时都会影响价格更新。网络异常时页面会显示状态，已取得的行情会保留。

在自选区输入股票代码即可查询和添加。例如 `600519` 或 `sh600519`。六位代码有歧义时请带交易所前缀，例如平安银行用 `sz000001`，上证指数用 `sh000001`。自选保存在当前浏览器，最多 26 个。

在线报价和日线使用公开接口，无需 API 密钥或付费订阅。请允许访问 `hq.sinajs.cn`、`push2.eastmoney.com` 和 `push2his.eastmoney.com`。

## 策略回测

选择标的、日期和一个或多个策略后运行。可对比策略收益、平仓胜率、最大回撤、资金曲线和逐笔成交。经典策略包括 MA5/MA20 均线交叉、MACD 交叉、RSI14 反转和布林带反转。

展开「自定义规则」，勾选「纳入本次回测」，输入如「三连阳开始买入」。阳线为收盘价大于开盘价，阴线为收盘价小于开盘价。持有时间按交易日计，包括买入当天。例如持有 5 天，第 5 天收盘后发出卖出信号，于下一交易日开盘成交。

- 日线从东方财富自动获取。默认指数使用指数点位，股票使用前复权价格。回测会拉取区间前的日线计算指标，并在北京时间 15:00 前跳过当天未收盘的日线。
- 模拟为单标的、单仓位全仓买入，收盘后确认信号，下一交易日开盘成交。单边费率在买卖时各扣一次，未单独模拟涨跌停、滑点、成交量约束或印花税。指数水平可用于策略比较，对应的可交易品种需要单独回测。
- 区间末尚未退出的持仓以当日收盘估值。胜率以盈利平仓笔数除以平仓总数。最大回撤取日终净值相对历史峰值的最大跌幅。
